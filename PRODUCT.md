# Meine Aufgaben
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
ChatGPT Sites with the supplied Vinext starter, Cloudflare D1, and a Site-hosted MCP server, as required by the deployment target and durable shared data.
## Users
One owner, on phone and computer; ChatGPT text and voice control are requested capabilities (voice was not independently tested).
## Product Purpose
Create, organize, complete and find tasks in project lists and date views without duplication.
## Capabilities and Constraints
Private owner-only access. One task row per task; shared website/MCP operations. Notes, dates and reminders. Today, this week, next week, this month. Selective list import and full JSON export. The import supports selected lists; no real task data is included.
## Brand Commitments
Explicit Apple Notes reference: simple lists, checkboxes, dark mode. German interface.
## Product Principles
- Keep routine work in the list.
- Preserve one source of truth.
- Expose conflicts rather than overwrite unseen changes.
- State reminder delivery limits clearly.
